ARPANET

A ARPANET foi uma rede de computadores criada em 1969 nos Estados Unidos. Ela conectava instituições de pesquisa e foi uma das precursoras da internet.

Principais pontos

  • Começou a funcionar em 1969.
  • Conectava computadores distantes.
  • Permitia compartilhar informações.
  • Utilizava a comutação de pacotes.
  • Contribuiu para o desenvolvimento da internet.

Importância

A ARPANET mostrou que computadores em diferentes lugares poderiam trocar dados por uma rede, contribuindo para a internet atual.

TCP/IP

TCP/IP é um conjunto de protocolos que permite a comunicação entre computadores conectados a uma rede, incluindo a internet.

Tim Berners-Lee e o CERN

Tim Berners-Lee criou a World Wide Web enquanto trabalhava no CERN, facilitando o acesso e o compartilhamento de documentos pela internet.

Mosaic e Netscape

Mosaic foi um dos primeiros navegadores gráficos populares. O Netscape surgiu depois e ajudou a popularizar a navegação na Web.

A guerra dos navegadores

Foi a disputa entre empresas que buscavam conquistar usuários para seus navegadores, especialmente durante a década de 1990.

DNS

O DNS traduz nomes de domínio, como exemplo.com, em endereços IP usados para localizar computadores e servidores.

HTTP e seus métodos

HTTP é um protocolo de comunicação da Web. Entre seus métodos estão GET, POST, PUT, PATCH e DELETE, usados em diferentes operações.

Códigos de status HTTP

São códigos que indicam o resultado de uma requisição. Por exemplo, 200 significa sucesso, 404 indica que o recurso não foi encontrado e 500 representa um erro interno do servidor.

HTTPS e certificados

HTTPS protege a comunicação entre o navegador e o servidor por meio de criptografia. Os certificados digitais ajudam a verificar a identidade do site.

HTML 4 × XHTML × HTML5

HTML estrutura o conteúdo das páginas. XHTML segue regras mais rigorosas de escrita, enquanto HTML5 trouxe recursos modernos para a criação de páginas e aplicações Web.

O W3C e o WHATWG

São organizações que trabalham no desenvolvimento de padrões e especificações para tecnologias da Web, ajudando a manter a compatibilidade.

CSS: origem e propósito

CSS é a linguagem usada para definir a aparência das páginas HTML, incluindo cores, fontes, espaçamentos e posicionamento dos elementos.

JavaScript (1995)

JavaScript é uma linguagem de programação criada em 1995. Ela permite adicionar interatividade e comportamentos às páginas Web.

AJAX e o Gmail

AJAX permite atualizar partes de uma página trocando dados com o servidor sem recarregar a página inteira. Essa técnica ajudou a tornar aplicações como o Gmail mais interativas.

Web 2.0

Web 2.0 descreve uma fase da Web marcada pela participação dos usuários, pelas redes sociais, pelos comentários e pela criação colaborativa de conteúdo.

APIs e JSON

APIs permitem que sistemas se comuniquem. JSON é um formato de texto usado para representar e trocar dados entre aplicações.

Motores de renderização

São componentes dos navegadores que interpretam HTML e CSS e transformam o código em conteúdo visual na tela.

PWAs

Aplicações Web Progressivas combinam recursos de sites com características de aplicativos, podendo oferecer instalação e funcionamento com conectividade limitada.

Responsividade e mobile

Responsividade é a adaptação do layout a diferentes tamanhos de tela, facilitando o uso de sites em celulares, tablets e computadores.

Web3

Web3 é um termo usado para ideias de uma Web com maior descentralização, frequentemente associada a blockchain e aplicações distribuídas.
